## New
- Updated to Telegram 12.10.6
- Plugins: install user-made scripts with permission review, source warnings, safe mode and developer mode
- [Appearance › Material 3 sliders](tg://settings/inu/material3-sliders)
- [Behavior › Keep previous chats open](tg://settings/inu/keep-chats-in-stack) when opening another chat
- [Messages › Edited message timestamp](tg://settings/inu/edited-message-date) can show the edit or original send time
- [Privacy & Security › Extra confirmation](tg://settings/inu/biometric-require-confirmation) after face or iris recognition
- [Chats › Optimized attachment menu](tg://settings/inu/lightweight-attachment-animation) for smoother media opening and higher-resolution previews
- Proxy settings: import multiple proxy links from the clipboard
- Global search: open cached users and chats by numeric Telegram ID
- Bot description photos and videos open in the media viewer
- Group permissions: separate controls for stickers, GIFs, games and inline bots
- Ukrainian translation

## Improved
- Translator: plugins can provide additional translation services
- Updater: downloads the APK matching the installed full or pluginless variant
- Multi-chat forwarding supports the no-quote option
- Settings search is case-insensitive
- Classic UI spacing and layout across action bars, tabs and message input
- Material 3 styling for sliders, the AI editor and logout options
- Attachment previews open more smoothly and load full quality when zooming or editing
- Network requests survive short background periods and recover more reliably from stale sessions

## Fixed
- Messages sent during a network session reset could receive a 1 January 1970 timestamp or fail repeatedly
- Channel updates could replay indefinitely after PTS advanced
- Server-detected links were not updated in sent messages
- PhotoViewer could crash after sending or scheduling edited media, when disabling profile photo blur or when opening some HDR images
- Transparent sticker cutouts progressively faded or darkened while editing
- Videos without thumbnails briefly showed a black placeholder
- Static attachment camera mode could render nothing, and the attachment panel could leave empty space without camera permission
- Reactions could blink when sending or when collapsing a quote
- Rich message previews omitted hashtags, mentions, custom emoji and other entities
- Malformed tables could crash rich messages and Instant View
- Opening another screen with the keyboard visible could leave a blank area or delay the transition
- Avatar previews could remain on a blurred placeholder, and tapping a forwarded sender avatar could open the wrong profile
- System back did not close a persistent bot keyboard correctly
- Search highlights were misplaced inside quotes
- Seekable GIF captions were hidden and releasing long-tap rewind could stutter
- Emoji status tabs could break for users without gifts
- Forum type cache access could race across threads
- Channel admin actions appeared for users without admin rights

## Plugins
- Initial sandboxed TypeScript API with scoped grants, per-plugin storage and lazy Telegram TL objects
- APIs for accounts, messages, media, files, networking, notifications, canvas, custom screens, menus and chat history
- Interceptors for API requests, server updates and outgoing messages
- `@inugram/plugin-types` typings and `@inugram/cli` commands for scaffolding, checking, building, pushing, live reload and evaluation

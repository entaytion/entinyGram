## Improved
- Long-tapping a link to a forum topic now shows a preview of it
- Big chats and busy channels hopefully no longer stall the message database for minutes
- Launcher shortcuts use adaptive icons
- Pinning chats found in search
- Android 12+: splash screen matches the selected app icon and Monet theme
- Plugins, fonts and settings in rich messages are now handled in-app

## Fixed
- OTA no longer sends a relaunch notification on Android 17
- More unread reactions counter drifting fixes
- Reply previews of deleted messages not cleared when several messages were deleted at once
- Channel messages deleted while the app was closed staying in the chat forever
- Shared media for channels you haven't joined, opened via a link from another chat
- Hopefully, black screen when cropping in the photo viewer
- Counters misaligned with some custom fonts
- Animated (webm) reactions misplaced while moving
- Selection header fade in global search with the classic UI
- Material 3 glitches in the chat editor, contacts icons and dividers of single-cell settings sections
- Monet: attach menu file icons and a white separator line in group calls
- Wrong title of the Chats settings page

## Plugins
- *breaking-ish:* `invokeRpc` applies `Updates` and `affectedMessages` results to the app, opt out with `{ processUpdates: false }`
- `getUserFullCached`, `getChatFullCached`, and a `force` option for `getUserFull`/`getChatFull`; non-cached reads now check the database first
- Action getters (`text`, `icon`, `visible`) may be async, within the same 150 ms menu budget
- A single visible action row is shown inline instead of in an "Actions" submenu
- `check` rows accept `onClick` to split the row body from the switch
- `inu eval` returns a parenthesized last expression correctly
- Docs: [screenshots of the UI elements](https://github.com/teidesu/inugram/blob/main/sdk/docs/elements.md)
